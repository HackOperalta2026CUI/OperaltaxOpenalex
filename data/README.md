# Exports datés

Déposez ici les exports de la carte vivante, avec la date dans le nom :

- `AAAA-MM-JJ_matrice_operalta.csv` : matrice importée dans Operalta (séparateur `;`)
- `AAAA-MM-JJ_resultats.json` : résultats bruts
- `AAAA-MM-JJ_carte.html` : version HTML autonome (données figées)

Ne remplacez jamais un ancien fichier. La série datée montre comment les preuves évoluent, et sert de source aux chiffres du pitch.
